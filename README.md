# React Banner Editor & Visual Design Studio

An interactive browser-based graphic design utility built with React and TypeScript to create, customize, and export social media banners, hero headers, and promotional cards.

## Key Features
- **Interactive Canvas & Layer System:** Full control over element positioning ($X/Y$), dimensions ($W/H$), rotation angles, border radius, and layer stacking.
- **Template Gallery:** Categorized starter templates (Hero banners, Social posts, Web headers, Promo cards) with instant search and filtering.
- **Typography & Vector Elements:** Rich text editing (font family, weight, size, alignment) combined with basic shapes, arrows, icons, image uploads, and visual adjustments/effects.
- **History & Export Workflow:** Undo/redo state history, project saving, and multi-resolution export.

## Relevance to Multimodal AI & UI Evaluation
Designing and testing complex visual interfaces strengthens the ability to evaluate AI-generated UI layouts, spatial alignment, typography hierarchy, and visual asset coherence.

## Development & Tech Stack
- **Stack:** React, TypeScript, HTML5, CSS3, Vite
- **Workflow:** Built through iterative prompt engineering, specifying canvas mechanics, property inspector controls, and template architecture while reviewing and validating code outputs.
